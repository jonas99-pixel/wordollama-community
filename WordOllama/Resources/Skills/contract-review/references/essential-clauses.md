# 合同必备条款审查指南

> **给 AI 助理的系统指令：**
> 在执行“第一步：必备条款检查”时，请严格对照本指南。对于发现的“缺失”或“约定不明”的情况，请调用 `add_comment(段落号, 建议内容)` 在合同对应位置或文末添加批注。

## 1. 通用必备条款（所有合同均须包含）

| 条款类别 | 审查重点（必须包含的要素） | 若缺失或模糊的批注建议 (Action) |
| :--- | :--- | :--- |
| **主体信息** | 双方全称、统一社会信用代码/营业执照号、注册地址、法定代表人/授权代表。 | “建议补充双方完整的法定名称、统一社会信用代码及联系地址，以防诉讼时主体认定困难。” |
| **合同标的** | 提供的具体服务范围、产品名称、规格型号、质量标准、数量。 | “标的描述过于笼统，建议以附件形式或在此处详细列明交付物的具体规格、质量验收标准及数量。” |
| **价款与支付** | 总金额、币种、含税/不含税价格、税率、支付节点（先决条件）、发票开具要求及类型（专票/普票）。 | “建议明确价格是否含税及具体税率，并补充付款的先决条件（如：收到合规发票后X个工作日内付款）。” |
| **履行期限与地点** | 交付标的/提供服务的准确起止时间、交付地点、运输与验收方式。 | “建议明确具体的交付/服务期限及履约地点。若涉及物流，建议明确运费及风险转移的节点。” |
| **违约责任** | 逾期付款/逾期交付的违约金计算方式（如按日千分之X）、严重违约的单方解除权、赔偿范围是否包含律师费/诉讼费。 | “违约条款缺失/过于原则，建议补充：1) 逾期付款/交付的按日违约金标准；2) 守约方维权费用（含律师费、诉讼费、公证费等）由违约方承担的条款。” |
| **争议解决** | 明确的管辖法院（如原告所在地、被告所在地、合同签订地）或明确的仲裁委员会名称。 | “争议解决条款缺失/约定不明。建议补充：‘因本合同引起的争议，双方应协商解决；协商不成的，应向【己方所在地/原告所在地】有管辖权的人民法院起诉’。” |
| **生效条件** | 签字+盖章生效，或附特定期限/条件生效。 | “建议明确合同生效要件，例如：‘自双方法定代表人或授权代表签字并加盖公章（或合同专用章）之日起生效’。” |

## 2. 专项/场景必备条款（根据合同性质触发）

> **AI 助理请注意：** 请根据合同的整体性质（如：技术开发、劳动、采购、合作）判断是否需要以下条款。如果需要但未发现，请在文末批注提醒。

| 条款类别 | 适用场景 | 审查重点与批注建议 |
| :--- | :--- | :--- |
| **保密条款** | 涉及商业秘密、技术秘密、用户数据、战略合作等。 | **审查重点**：保密信息定义、保密期限、违约金。<br>**批注建议**：“本交易涉及商业/技术机密，建议补充保密条款，明确保密期限（如：合同解除后2年内）及泄密违约金。” |
| **知识产权** | 委托开发、设计、技术服务、品牌授权等。 | **审查重点**：背景知识产权归属、前景知识产权（新产生IP）的归属及使用权。<br>**批注建议**：“本合同涉及智力成果产出，建议明确约定项目交付物及前景知识产权的归属（建议约定归委托方所有）。” |
| **不可抗力** | 长期合同、工程合同、国际贸易、受政策影响较大的行业。 | **审查重点**：不可抗力事件定义、通知义务（需在X日内提供证明）、免责范围。<br>**批注建议**：“建议补充不可抗力条款，并明确遭遇不可抗力一方应在X日内书面通知对方并提供相关机构证明，否则不予免责。” |
| **通知与送达** | 所有涉及后期争议可能的商业合同。 | **审查重点**：指定的联系人、通讯地址、电子邮箱；约定“该地址同样适用于司法文书送达”。<br>**批注建议**：“建议补充《通知与送达》条款，明确双方的有效送达地址及邮箱，并明确约定该地址适用于法院/仲裁机构的司法文书送达，防范对方失联导致诉讼程序拖延。” |

## 3. 动态检查逻辑规则

如果遇到以下情况，请立刻触发对应规则：
- **发现“订金”字样**：提示是否需要修改为“定金”（注意二者法律效力不同，定金有双倍返还罚则）。
- **发现“违约金”与“定金”同时存在**：批注提醒：“《民法典》规定违约金和定金罚则不能同时适用，守约方只能择一主张。”
