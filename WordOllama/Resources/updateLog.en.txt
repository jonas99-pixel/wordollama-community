Version V2.1.0 2026/07/17

Changes
1. Optimize the Agent interface and functionality;
2. Added a review workbench feature, which allows users to view a list of document review issues and quickly jump to the corresponding location.
3. Optimized settings page;
4. By default, Agent permissions are tightened to reduce the risk of accidental operations;
4. Some infrequently used functions have been removed to reduce interface complexity;
5. Fixed some known bugs.

Version V2.0.5 2026/06/05

Changes
1. Improved Agent features and added the review issues panel, allowing users to view the issue list and jump directly to the corresponding document location.
2. Fully integrated MCP tool support, including stdio, Streamable HTTP, and legacy SSE transports, with configurable remote MCP URLs, request headers, working directory, and environment variables.
3. Improved MCP stability, including paginated tool discovery, initialized notifications, server ping handling, Windows .cmd/.bat startup, safe tool-name conversion, and process cleanup.
4. Improved online model tool-calling compatibility, including OpenAI-compatible APIs, Claude, Gemini, and Ollama tool-call adaptation.
5. Fixed an issue where multiple system tray icons could remain in the lower-right corner.

Changes

2. Added the Generate Table feature:
You can input text and generate a table with one click, then insert it into the document. Because AI output can be unstable, table parsing may fail. If an error occurs, please regenerate several times.
