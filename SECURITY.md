# Security Policy

WordOllama can send document text to configured AI providers and can optionally call external Agent tools or MCP servers. Treat provider credentials, document contents, Skill files, and MCP configuration as sensitive.

Please report vulnerabilities privately through the contact channel listed on the [project website](https://www.wordollama.com). Do not publish credentials, private documents, exploit details, or a working malicious MCP configuration in a public issue.

The detailed user-safety notes and reporting checklist are in [docs/SECURITY.md](docs/SECURITY.md).
